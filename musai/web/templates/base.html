{# The shell every signed-in page lives in. ── The accent system ─────────────────────────────────────────────────────────────────────── A page declares which feature it belongs to with `{% block feature %}dates{% endblock %}`, and that lands on ``. Every accent-coloured thing on the page — buttons, the current tab, focus rings, chips — reads `var(--accent)`, so **one attribute re-colours the whole screen**. Adding a feature is one CSS block, not a class rename across nine templates. This is why the accents are CSS custom properties and not Tailwind colour keys: a Tailwind key has to be spelled out at every call site (`text-clay-700`, `bg-clay/10`, `border-clay/20`), which means a component can only ever belong to the feature it was written for. The old `clay`/`sage` keys are kept below for templates not yet converted; they are aliases of the indigo/teal values and nothing new should use them. 🔴 Danger red is NOT in the accent rotation.
