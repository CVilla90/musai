What it does

Four jobs, each one a full afternoon by hand.
Build

Copy a course that works

Restore a finished course into another group — sections, dates, filters and tab visibility intact — then count it back from a fresh login, because a restore's own report has been wrong more often than it has been right.

Schedule

Date every activity

Cut the semester into partials and write open and close dates across every quiz, assignment and forum. Each one is read back from its own settings form, which is the only reading that tells the truth.

Grade

Compute the partial, exactly

General 60, Special 20, Exam 20. The exact machine grade is kept untouched; curves and extra credit are separate, visible layers on top of it, never edits to the original.

Reach

Write to a whole group

One message to every student in a course, recorded before it is sent so that a retry can never deliver it twice. Who was skipped is stored too, with the reason.

The three rails

A cut track is a position the code cannot reach. An unbroken one is a switch you can throw.
Rail 1

Save, never confirm

The SEGA adapter can click Guardar. It has no code path to Confirmar — not a disabled button, not a warning dialog, simply no route there at all.

Save Confirm

Confirming a grade is yours, and stays a human act.

Rail 2

Dry-run by default

Every write to a live system is simulated first and prints what it would have done. This is the one rail with a far end you can actually reach — deliberately, because a real write has to be a decision somebody made out loud.

Rail 3

SUSAI is read-only

The student assistant runs in its own process, as its own database role. It can append to a conversation and nothing else. It cannot see the grading code, let alone run it.

The other half

Your students never see this console.

SUSAI · on WhatsApp

Students ask WhatsApp, not you.

MUSAI inspires the professor; SUSAI supports the students. Deadlines, grades and what is due next — answered on the number they already have open, at eleven at night, without a login and without reaching you.

It reads. It never grades, never edits a course, and never sees a roster it was not asked about.
